## Repairs made in this audit

1. **Copied correction excerpts cannot receive independent credit.** Previously the deterministic guard compared the whole previous Supervisor message with the whole answer. A student could paste only its factual correction, leaving off the appended application question, and a mistaken model verdict could mark it independent. The shared guard now recognizes a literal answer excerpt inside the latest correction, normalizes case/whitespace and terminal sentence punctuation, and marks it assisted before validation. The standalone decision validator rejects independent credit for the same case. This is a literal-copy check, not a paraphrase detector; fresh application and semantic independence remain evaluator responsibilities. The evaluator version is now `evaluator-2026-10-01-v7`.
2. **Three unsuccessful attempts offer checked support and a pause.** The server counts saved assessments for the same objective, including the current assessment. At three unsuccessful attempts, it uses the existing source-backed correction and application question plus a supportive pause invitation. It keeps the goal unresolved and the learner free to continue or use the existing Pause action. Independent correct evidence bypasses the nudge. No new model call or teacher action is needed. Counts are cumulative per objective within this session.
3. **Mixed uncertainty stays unresolved.** When a single answer has both an incorrect assessment and an unverified assessment, source-review handling takes priority over an ordinary corrective next turn. A correction must not conceal an unresolved source claim.
4. **Avoid the final cosmetic model call.** When the provisional remaining-objective list is empty, reply generation returns the selected authored turn without calling the model to rewrite a question that the completion transaction would discard. This is only a cost/latency shortcut. It does not emit a completion verdict: the existing SQL transaction still checks durable required evidence and unresolved interventions and may refuse completion.
5. **Fetch independent turn context concurrently.** Existing history, intervention and progress reads, plus the assessment count input, are awaited together after evaluation. Mutations and lease checks retain their order.

No dependency, schema migration, teacher-facing product, paid call or external deployment was added by this audit.
