# T14 teacher publication

Implemented locally 26 September 2026. A teacher can select an active class when saving material through T05, map one objective from an exact saved page quote with a structured form, inspect the source/reference/objective map, edit common fields, mark exact saved-page references as checked or conflicting, approve the current saved version, then explicitly publish it to the owning active class. The advanced schema 1.1 JSON import remains for larger drafts. There is no automatic generation or fabricated review. A complete school walkthrough still needs hosted synthetic account verification.

The teacher review API requires live identity, teacher role, same origin, bounded JSON, active class ownership, and the exact current immutable version ID. Edits reset review. Missing evidence, unresolved issues, conflicting or unverified references, scope-only sources and illustrative fixtures block approval. Approval records the authenticated teacher and creates an append-only reviewed version; publication creates an append-only published version and atomically points the class lesson at it. Learners continue to see only their class's current published version through existing RLS/session checks. Private preparations cannot publish. No provider call is made.
