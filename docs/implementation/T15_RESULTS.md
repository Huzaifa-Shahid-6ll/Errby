# T15 results and teacher summaries

The learner recap rechecks current session access before any service-role read; removed class members and archived lessons cannot expose old results. The teacher API and page require an active owned class and select only `visibility='class'` sessions for one lesson version. They show the latest session for each active class member. Private sessions never enter teacher results.

Required goal state comes from saved `objective_progress`. First try counts each required objective's first independent, unassisted, scorable evaluation; unverified and off topic evaluations are excluded and counted separately. The new migration preserves the evaluator's independent flag; historical evaluations have `NULL` and cannot enter the first try denominator. Unresolved interventions or required unverified goals take precedence. A session is labelled Explained only when persisted status is completed and all required goals are explained.

Migration `20260927000600_results_activity_review.sql` adds activity collection and audited assessment review. The foreground client emits at 15-second intervals while the learner is reading or typing, stops after 60 seconds without activity, and excludes hidden tabs, paused states and provider waits. The server accepts at most 15 seconds, bounds increments by elapsed server time, serializes sessions and deduplicates event IDs. State changes reset the server interval. The recap labels accepted activity time as an estimate and says Not measured when no interval was accepted. No keystroke content is collected.

Evidence matches objective IDs, including when titles repeat. Correct-after-help counts required goals whose first scorable attempt was incorrect/partial and which now have explained state after an intervention. Corrections count distinct persisted misconception IDs resolved with explained objective evidence. First-try summaries apply audited verdict revisions, label revised results, and preserve the original model evaluations. Class averages show the eligible participant count and exclude untested learners.

Teachers expand a class learner's assessments to read the saved answer, evidence excerpt, model uncertainty, checked lesson references and previous review reasons. Explicit revision submission requires a reason and the expected current verdict. The transaction rechecks ownership/access, appends `assessment_revisions`, recomputes the latest objective evidence and session completion, and leaves original model evidence intact. Correct revisions cannot manufacture independence, quotes or checked references; copied Supervisor text is rejected. Older revised attempts cannot replace newer learner evidence. Any unresolved intervention or required uncertainty blocks completion. Learners see uncertainty reasons and whether their recap was revised.
