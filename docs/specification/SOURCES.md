# Sources and provenance
Checked 16 September 2026. This pack is mostly original product/engineering design based on the user's decisions. It is not a literature review or a legal opinion. Prices, product limits and event rules can change.

- User conversation: product name, audience, school setting, source preparation, typed flow, supervisor, analytics, visual references, team and deadline horizon.
- User-supplied Lovable light/dark screenshots: layout and visual inspiration only; no affiliation or source-code reuse.
- [FirstCommit rules](https://firstcommit.devpost.com/rules): deadline, team/contribution, source history and AI rules; summarised only in LAUNCH_AND_DEMO.md.
- [Next.js App Router](https://nextjs.org/docs/app): framework documentation for selected architecture.
- [Supabase pricing](https://supabase.com/pricing): free-plan constraints.
- [Supabase RLS](https://supabase.com/docs/guides/database/postgres/row-level-security): access-control primitive.
- [Vercel Hobby](https://vercel.com/docs/plans/hobby): hosting conditions and plan limitations.
- [GPT-4.1 mini](https://developers.openai.com/api/docs/models/gpt-4.1-mini): model candidate and listed token prices.
- [OpenAI under-18 API guidance](https://developers.openai.com/api/docs/guides/safety-checks/under-18-api-guidance): minor-facing API deployment requirements.
- [OpenAI data controls](https://developers.openai.com/api/docs/guides/your-data): retention controls; application settings alone do not establish provider retention.
- [Gemini API terms](https://ai.google.dev/gemini-api/terms): reason not to choose its Developer API for the proposed under-18-facing app.

No efficacy claim is derived from Duolingo or Feynman's name. UX choices (prominent composer, distinct supervisor, concise clarification, truthful progress) are hypotheses to test. The actual visual mockups are generated concepts, not reference screenshots of an implemented app.

Name availability has not been legally cleared and domain availability is not promised. Earlier preliminary name searches are preserved in DISCOVERY_HISTORY.md.
