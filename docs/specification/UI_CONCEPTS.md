# UI concept briefs
Two raster visual concepts were requested using the built-in image-generation tool. They are delivered inline in the conversation and saved automatically there. They are not application files or implemented screens.

## Shared direction
High-fidelity flat desktop UI, original Errby branding, charcoal rounded shell and thin navigation rail, restrained blue/lilac halo, readable large text, no browser frame or 3D perspective. Use the user's two Lovable screenshots as style/layout references only. Keep the primary learning activity visible. No voice controls.

## Home prompt
Show the heading “What are you teaching Errby today?” above a wide topic/resource composer with “Describe a topic or paste a resource link…”, Add material and Prepare lesson. Below it show Your class lessons with Heat transfer, Equivalent fractions and Plant cells. Slim rail and small errby wordmark. The halo blooms behind the input and fades into dark solid surfaces. No promotional hero or product feature grid.

## Session prompt
Show Heat transfer and objective progress, a typed conversation between Errby and You, and a separately labelled Supervisor panel. Example false agreement: Errby asks whether ice creates its own heat; learner agrees. The supervisor calmly corrects this with an amber border/shield, source reference and a question inviting re-explanation. Right-side learning goals; bottom text composer. No fabricated real student data or punitive red treatment.

## Interpretation and implementation
Sample counts and lesson text are illustrative. Review exact conceptual progress against the teaching state before implementation. Use status labels and icons along with colour. Token values, layouts and responsive rules are in DESIGN_SYSTEM.md and SCREEN_INVENTORY.md. A static illustration cannot validate keyboard use, screen readers, contrast, mobile behaviour or runtime learning logic.
