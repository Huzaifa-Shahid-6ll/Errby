# Errby landing motion research

Updated 30 September 2026 for the conversation-led concept page. This replaces implementation-specific conclusions from September 19. Historical raw evidence is retained, not claimed as today's verification.

## Live reference refresh

T3 collaborative browser, 1280×800 CSS pixels, 30 September 2026. Inspected initial-load headings, public controls, active CSS/Web Animations and video states on all 12 URLs below (12 domains). Exact implementation, complete replay behavior and hover choreography are not inferred from those samples. No private flows or purchases. No mobile reference review in this refresh; [earlier desktop/mobile evidence](live-reference-observations.md) remains historical. Zero active animations does not exclude JS/canvas motion. [Raw observations](reference-evidence/2026-09-30-observations.json).

| Reference / hero or navigation                          | Observed load/state                                                      | Transfer / boundary                                     |
| ------------------------------------------------------- | ------------------------------------------------------------------------ | ------------------------------------------------------- |
| [Khanmigo](https://www.khanmigo.ai/)                    | Hero audience links and role headline; no CSS animation/video at sample. | Keep audience navigation; do not rotate text.           |
| [Synthesis](https://www.synthesis.com/tutor)            | Multiple autoplay videos playing; Play video control.                    | Demonstration matters; reject autoplay.                 |
| [MagicStudent](https://www.magicschool.ai/magicstudent) | Teacher/student framing; cookie overlay; no animation sampled.           | Explain teacher review, no transferred safety promises. |
| [Brilliant](https://brilliant.org/)                     | 300ms transitions active; autoplay videos paused; two audience actions.  | Keep actions immediate, no live-looking tutor.          |
| [Linear](https://linear.app/)                           | Repeating 2800ms animations active beside product framing.               | Reject continuous loops.                                |
| [Notion](https://www.notion.com/)                       | 150/300ms transitions; Play affordance; non-autoplay video paused.       | Visitor controls the example.                           |
| [Stripe](https://stripe.com/)                           | 1200/300ms animation samples; changing GDP metric.                       | No fictional counters.                                  |
| [GOV.UK](https://www.gov.uk/)                           | Service navigation and cookie controls; no animation/video sampled.      | Static native navigation.                               |
| [Pentagram](https://www.pentagram.com/)                 | 300ms transitions; autoplay video elements paused; cookie overlay.       | No heavy media treatment.                               |
| [COLLINS](https://www.wearecollins.com/)                | 1000/2000ms arrival animations active.                                   | Distinctive art without delayed content.                |
| [Headspace](https://www.headspace.com/)                 | 100ms transitions sampled; no video sampled.                             | Short control feedback; no health claims.               |
| [W3C WAI](https://www.w3.org/WAI/)                      | Accessibility navigation; no animation/video sampled.                    | Semantic controls without choreography.                 |

These observations are bounded sampling, not a full interaction/accessibility audit or evidence of conversion gains. Cookie overlays were left untouched.
