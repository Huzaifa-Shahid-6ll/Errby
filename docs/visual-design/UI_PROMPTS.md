## Shared prompt

Use case: ui-mockup. Create ONE high fidelity flat browser-application screen for Errby, an English school app where learners teach an intentionally confused robot. It is part of a CONSISTENT 14-screen design suite. References are style/brand references only: first image provides the Lovable central composer / rounded shell composition; second provides Errby's existing friendly small white robot and wordmark. Do NOT copy Lovable text or logos. Do NOT reuse the dark theme unless specifically requested below.
Shared LIGHT theme: cool neutral canvas #F7F9FC, solid white surfaces, deep navy body text #17223B, slate secondary text #526179, primary indigo #4F46E5 with white button labels. Errby messages pale #EEF2FF with deep indigo #4338CA identity. Supervisor messages warm pale #FFF7E6 with brown #92400E text, amber #B45309 border and shield icon. Success teal #0F766E. This is a restrained futuristic minimal product, suitable for ages about 8-18 without childish rainbow decoration. Soft diffuse blue/lilac HALO only behind home/empty-start areas, nearly absent during reading. No neon text, no gradient behind body copy, no tiny text. Clear modern sans serif, 18px-scale body, 14px minimum labels. Mostly neutral surfaces, colour reserved for meaning.
Consistent shell: left 76px slim white rail, indigo e monogram at top, outline home/book/class/history/settings icons, simple circular learner avatar at bottom. Main rounded shell, spacious 24px gutters. All visible icons from a coherent simple outlined family. Include small top-left 'errby' wordmark where appropriate. Actual working screen, no device mockup, browser frame, decorative background outside app, marketing hero, microphone, billing, streaks, leaderboard. Landscape 16:10 composition at high resolution. Tiny discreet footer text 'Design concept · Sample data'. Keep all requested content inside safe margins. Do not introduce unrelated functionality.
